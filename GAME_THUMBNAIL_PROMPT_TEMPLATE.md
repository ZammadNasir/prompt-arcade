## Prompt Arcade - Game Thumbnail Generation Prompt

Generate a **high-quality 16:9 game thumbnail image** for a browser game called:

**{GAME_NAME}**

---

## Context

This image will be used as a game cover inside a modern arcade-style game website called "Prompt Arcade".

The thumbnail will be displayed in a **card UI layout with a 16:9 aspect ratio**, shown in a grid alongside other games.

It must look like a **professional game store cover image (Steam / Xbox / PlayStation style)**.

---

## Visual Style Requirements

- Cinematic game cover art
- High contrast and visually readable at small sizes
- Strong central focal point
- Clear subject (character, scene, or action moment)
- Depth and lighting that makes it feel like a real game
- Slight motion or action feel preferred

Avoid flat or abstract visuals.

---

## Composition Rules

- Must be **landscape (16:9)**
- Center or slightly off-center focal subject
- Background should support the theme but not overpower subject
- Leave subtle empty space around edges (for UI cropping safety)
- Do NOT place important details near edges

---

## Game Type Context

This game is inspired by:

**{GAME_DESCRIPTION_OR_PROMPT}**

Examples:

- FPS shooter in a war zone
- Racing game in a neon city
- Sandbox block building game
- Physics destruction game
- Top-down survival game

Use this context to shape the visual theme.

---

## Style Direction

Choose a style that feels like:

- AAA game cover art OR
- Stylized indie game poster OR
- Cinematic action scene

Lighting:

- Dramatic
- High contrast
- Slight bloom or glow allowed (but not excessive)

Camera:

- Dynamic angle preferred (not flat top-down unless required)
- Sense of scale or action

---

## STRICT RULES

- No text on image
- No logos
- No watermarks
- No UI elements
- No readable words anywhere
- No real game branding (Call of Duty, GTA, etc.)
- No copyrighted characters

---

## Output Goal

The final image should look like:

> A real Steam/Xbox/PlayStation game cover for a fictional game

It should feel clickable, exciting, and visually clear even at small thumbnail size inside a UI card.

---

## Example Prompt Output

If GAME_NAME = "Call of Wars"

and description = FPS war shooter

You generate:

> Cinematic first-person shooter battlefield scene, futuristic soldiers in combat, explosive action, dramatic lighting, military sci-fi environment, cinematic depth of field, AAA game cover style, ultra detailed, 16:9 composition, centered hero soldier, smoke and debris in background, high contrast lighting, no text, no logos

---

## Final Instruction

Always optimize for:

**Clarity > Beauty > Complexity**

Note the image should be .PNG

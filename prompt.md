# Prompt Arcade - Project Generation Prompt

Build a complete production-ready MVP called "Prompt Arcade".

## Project Overview

Prompt Arcade is an open-source website that hosts AI-generated browser games.

The purpose of the project is not to host perfect games. The purpose is to showcase games generated by AI models from prompts.

Games may be simple, buggy, weird, incomplete, or surprisingly good.

Think of the website as an arcade and museum of AI-generated games.

The site must be fast, simple, static-first, and easy for contributors to add new games.

---

## Tech Stack

Use:

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- shadcn/ui

Do NOT add:

- Prisma
- Database
- Redux
- Zustand
- Authentication
- Server actions unless necessary
- Complex backend infrastructure

Keep everything static and filesystem-driven.

---

## Core Architecture

Create this structure:

/app
/page.tsx
/game/[slug]/page.tsx

/games
/call-of-wars
/game.tsx
/thumbnail.png
/meta.ts

/lib
/games.ts

/components

/public

Each game lives in its own folder.

The website should automatically discover games from the games directory.

Avoid manually creating routes for every game.

Use dynamic routing.

## Game Metadata

Each game should export metadata like:

{
slug: "call-of-wars",
name: "Call of Wars",
description: "AI generated FPS game",
genre: "FPS",
generatedWith: "Codex",
status: "Playable",
thumbnail: "/games/call-of-wars/thumbnail.png",
prompts: [
"Create FPS game",
"Add enemies",
"Add shooting mechanics"
],
knownIssues: [
"Enemies occasionally freeze",
"Reload animation missing"
]
}

Create strong TypeScript types.
